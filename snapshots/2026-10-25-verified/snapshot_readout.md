# 2026-10-25 synthetic snapshot readout

This is a dated **synthetic** evaluation, not a real-transcript result or a public model ranking. Four threads contain 14 ordered sessions. Nine writers produced 126 checkpoint records; 124 writer responses were valid JSON. The two failures were Qwen3.8 Max responses on the Northstar review-reschedule and rollout-scope sessions. The primary GLM judge scored 124/124 valid writer checkpoints. An independent Gemini judge scored 126/126 full checkpoint stores (including the two invalid writer responses), 186/186 blinded final-store entries, and 240/240 applied add/update writes. Both final-store API timeouts were retried successfully. All 13 writes Gemini labeled unsupported were classified with zero classifier errors.

The applied-write denominator includes successful additions and updates even when later corrected or deleted. Gemini labeled 13/240 (5.4%) as unsupported by explicit user statements, 9/240 (3.8%) as supported but not worth storing, and 1/240 (0.4%) as uncertain. Eleven of the 13 unsupported writes were classified as relying on a non-user source; two were unsupported inferences. These are automated labels, not human-verified factual errors. In particular, "non-user source" can describe a potentially true tool result that the user did not explicitly confirm.

The judges disagree materially on error counts. For the local writer, GLM reported 26 hallucinated entries over valid checkpoints while Gemini marked 14 unsupported entries across full checkpoints. Their categories and rubrics are not identical, and no human adjudication has reconciled them. Do not publish a comparative ranking or a claimed hallucination rate from these numbers alone. Inspect the row-level sheets and evidence before public claims.
